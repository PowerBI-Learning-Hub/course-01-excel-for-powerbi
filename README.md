# Preparing Data for Analysis with Microsoft Excel

Part of the **PowerBI-Learning-Hub** learning ecosystem.

This repository contains practical, beginner-friendly, and certification-oriented notes, exercises, and learning resources for the first course of the Microsoft Power BI Data Analyst Professional Certificate.

The focus of this repository is:

* practical understanding,
* real-world data preparation,
* Excel fundamentals for Power BI,
* and PL-300 preparation.

---

# Course Overview

Before working with Power BI, data must be:

* clean,
* organized,
* validated,
* and analysis-ready.

This course focuses on preparing Excel data for analytics workflows and Power BI integration.

You will learn how to:

* organize datasets,
* clean messy data,
* use formulas,
* transform spreadsheet data,
* and prepare business-ready information for analysis.

---

# Learning Objectives

By the end of this course, you should be able to:

* Understand the role of Excel in data analytics
* Prepare datasets for Power BI
* Use common Excel formulas and functions
* Clean and structure raw business data
* Perform basic data transformation
* Improve data quality and consistency
* Work with tables and ranges efficiently
* Build an Excel workflow for analytics projects
