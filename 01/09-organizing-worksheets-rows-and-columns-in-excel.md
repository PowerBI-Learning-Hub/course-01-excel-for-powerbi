# Organizing Worksheets, Rows, and Columns in Excel

## Core Idea

This lecture explains how to:

* Organize Excel worksheets efficiently
* Manage rows and columns
* Resize spreadsheet elements
* Insert/delete rows and columns
* Hide and unhide worksheet content

Simple understanding:

> Well-organized worksheets make large datasets easier to navigate and analyze.

---

## Why This Matters

Large spreadsheets quickly become difficult to manage.

Poor worksheet organization can cause:

* Confusion
* Data entry mistakes
* Slow analysis
* Hard-to-read reports

Good worksheet management improves:

* Productivity
* Navigation
* Readability
* Data organization

This becomes very important in:

* Business reporting
* Data analysis
* Financial tracking
* Power BI preparation

# Working with Rows & Columns

## Resizing Columns

Columns may become too narrow.

Problems caused:

* Hidden text
* Scientific notation
* #### symbols

Example:

```text id="dz5npv"
1E+09
```

means the column is too narrow.

---

## Resize Methods

### Manual Resize

1. Hover between column headers
2. Drag left/right

---

### AutoFit Shortcut

Double-click column border.

Excel automatically adjusts width.

Very useful shortcut.

---

## Resizing Rows

Used when:

* Text is wrapped
* Content is hidden
* Larger spacing is needed

Resize by:

* Dragging row borders
* Double-clicking for AutoFit

---

# Inserting Rows & Columns

## Insert Column

Select the column to the RIGHT of desired location.

Then:

```text id="gph3jw"
Home → Cells Group → Insert
```

---

## Insert Row

Select the row BELOW desired location.

Then insert.

---

## Right-Click Shortcut

You can also:

* Right-click
* Select Insert

Very commonly used.

---

# Deleting Rows & Columns

Methods:

* Home tab
* Right-click menu

Used to remove:

* Unnecessary data
* Blank rows
* Old columns

---

# Hide & Unhide

Useful for large spreadsheets.

---

## Why Hide Columns/Rows?

To temporarily remove:

* Sensitive data
* Helper columns
* Unnecessary fields

without deleting them.

---

## Hide Steps

```text id="rj2s1m"
Home → Format → Hide & Unhide
```

Then choose:

* Hide Rows
* Hide Columns

---

## Identifying Hidden Columns

Example:

```text id="m48g52"
F → H
```

Missing G means:

> Column G is hidden.

---

## Unhide Columns

Select surrounding columns first.

Example:

* Select F and H
* Unhide G
