# Course Introduction — Microsoft Excel for Data Analysis

## Core Idea

This course teaches beginners how to use Microsoft Excel for data analysis in business scenarios.

You’ll learn how to:

* Work with spreadsheets
* Organize and clean data
* Use formulas and functions
* Prepare data for Power BI
* Build foundational analytics skills

Simple understanding:

> Excel is one of the first and most important tools in a data analyst’s journey.


## Power Tips

### Learn Shortcuts Early

Huge productivity improvement.

Important shortcuts:

| Shortcut         | Purpose       |
| ---------------- | ------------- |
| Ctrl + S         | Save workbook |
| Ctrl + T         | Create table  |
| Ctrl + Shift + L | Apply filters |
| Alt + =          | AutoSum       |

---

### Use Tables Instead of Raw Data Ranges

Benefits:

* Better formulas
* Easier filtering
* Cleaner formatting
* Dynamic updates

---

### Focus on Understanding, Not Memorization

Best learning method:

1. Watch
2. Practice
3. Break things
4. Retry
5. Repeat

---

### Build Small Projects

Mini practice projects improve learning much faster than passive watching.
