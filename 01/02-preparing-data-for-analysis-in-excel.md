# Preparing Data for Analysis in Microsoft Excel

## Core Idea

This course teaches you how to:

* Work with large datasets in Excel
* Clean and organize messy data
* Use formulas and functions
* Prepare data for analysis and reporting
* Build a strong foundation for data analytics and Power BI

Simple understanding:

> Raw data is usually messy.
> Excel helps transform that raw data into useful business information.

---

## Why This Matters

Businesses make decisions using data.

But raw data is often:

* Unorganized
* Inconsistent
* Difficult to read
* Full of errors

Before analysis can happen, data must be:

1. Cleaned
2. Structured
3. Standardized
4. Organized

This is one of the most important real-world skills for a data analyst.

---

Used to standardize messy text.

Examples:

* TRIM

* LOWER

### Date & Time Functions

Used for:

* Timelines
* Reports

Examples:

* YEAR

Important functions:

* IF
* IFS
* AND
* OR

Used for decision-making logic inside spreadsheets.

Example:


A company exports sales data from its system.

Before analysis:

* Clean the text
* Standardize dates
* Remove duplicates
* Apply formulas
* Organize into tables

That is real-world data preparation.

## Power Tips

### Use Tables Instead of Plain Ranges

Excel Tables provide:

* Better formatting
* Easier formulas
* Dynamic ranges
* Cleaner analysis

Shortcut:

```text
Ctrl + T
```

---

### Learn Keyboard Shortcuts Early

Huge productivity boost.

Important shortcuts:

| Shortcut          | Purpose               |
| ----------------- | --------------------- |
| Ctrl + T          | Create table          |
| Ctrl + Shift + L  | Apply filter          |
| Alt + =           | AutoSum               |
| Ctrl + Arrow Keys | Navigate data quickly |

---

### Clean Data First

Before creating charts or reports:

1. Remove duplicates
2. Standardize text
3. Fix blanks/errors
4. Validate dates
