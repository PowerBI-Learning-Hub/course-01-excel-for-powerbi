# Entering and Formatting Data in Microsoft Excel

## Core Idea

This lecture explains how to:

* Enter data into Excel
* Format worksheets for readability
* Use Excel shortcuts and formatting tools
* Improve spreadsheet clarity and usability

Simple understanding:

> Good formatting makes data easier to read, understand, and analyze.

---

## Why This Matters

Raw spreadsheets can become:

* Confusing
* Difficult to read
* Hard to analyze

Proper formatting helps:

* Improve readability
* Reduce mistakes
* Highlight important information
* Make reports more professional

In real businesses:

> Well-formatted spreadsheets improve communication and decision-making.

---

## Key Concepts

### Entering Data in Excel

Data is entered into:

* Cells
* Rows
* Columns

You can:

* Click cells manually
* Use keyboard arrow keys
* Press Enter to confirm entries

---

### Cell Alignment Behavior

Excel automatically aligns data based on type.

| Data Type | Default Alignment |
| --------- | ----------------- |
| Text      | Left              |
| Numbers   | Right             |

---

### Formula Bar

Shows the actual content inside the selected cell.

Useful for:

* Viewing formulas
* Editing data
* Checking hidden content

---

## Excel Features & Shortcuts

# AutoComplete

Excel suggests repeated text automatically.

Example:

Typing:

```text id="2v7s7r"
P
```

may suggest:

```text id="6a5k2u"
Partner
```

Useful for:

* Faster data entry
* Repeated values
* Large datasets

---

# Autofill

Used to copy values quickly into nearby cells.

How it works:

1. Select cell
2. Drag small square from bottom-right corner
3. Fill adjacent cells automatically

Useful for:

* Repeated text
* Dates
* Number sequences

---

# Undo Feature

Reverses recent actions.

Shortcut:

```text id="w2u6w0"
Ctrl + Z
```

Very important for beginners.

## Formatting Data

### Why Formatting Matters

Formatting helps users quickly understand:

* Currency values
* Percentages
* Dates
* Headers

---

# Number Formatting

## Currency Format

Used for financial values.

Adds:

* Currency symbol
* Decimal places
* Proper number display

---

## Comma Style

Adds:

* Thousands separator
* Decimal formatting

Example:

```text id="26gv2w"
1000000 → 1,000,000.00
```

---

## Percentage Format

Adds percentage formatting.

Important behavior:

> Excel multiplies the value by 100.

Example:

```text id="9lyx2y"
0.25 → 25%
```

---

## Decimal Controls

Buttons available to:

* Increase decimals
* Decrease decimals

Useful for cleaner reporting.

---

## Text Formatting

### Wrap Text

Used when text is too long for a cell.

Instead of overflowing:

* Text wraps into multiple lines

Very useful for:

* Headers
* Notes
* Descriptions

---

### Font Formatting

You can change:

* Font size
* Font style
* Background color
* Text color

Used to emphasize important data.

---

### Alignment Formatting

Options include:

* Left align
* Center align
* Right align

Often used for:

* Headings
* Tables
* Reports

---

## Format Painter

One of Excel’s most useful shortcuts.

Used to:

> Copy formatting from one cell to another.

Copies:

* Font styles
* Colors
* Alignment
* Borders
* Wrap text settings

## Power Tips

### Use Consistent Formatting

Professional spreadsheets should have:

* Uniform fonts
* Consistent colors
* Standardized number formats

Too many colors reduce readability.

Use formatting intentionally.

Helps maintain cleaner worksheet layouts.
