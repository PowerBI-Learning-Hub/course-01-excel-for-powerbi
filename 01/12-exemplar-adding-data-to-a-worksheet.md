## Purpose

Remove data no longer needed in the report.

---


# Fix Numbers Stored as Text

## Problem

Cell value aligns left because Excel detects it as text.

Usually caused by:

* extra symbols
* apostrophes
* spaces

---

## Steps

1. Double-click problematic cell

2. Remove unwanted symbol

3. Press:

   ```text id="mj9s0y"
   Enter
   ```

---

## Result

Excel converts value back to numeric format.

---

## Important Observation

| Alignment | Usually Means |
| --------- | ------------- |
| Left      | Text          |
| Right     | Number        |

# Use Autofill

## Purpose

Quickly copy repeated values.

---

## Steps

1. Type first value

2. Hover bottom-right corner of cell

3. Drag black cross downward

---

## Result

Excel fills remaining cells automatically.

---

## Productivity Tip

Autofill is one of the biggest Excel time savers.

# Format Main Headers

## Purpose

Improve worksheet readability.

---

## Steps

1. Select heading range

2. Go to:

   ```text id="hjlwm3"
   Home → Font Group
   ```

3. Apply:

   * larger font
   * background color

4. Go to:

   ```text id="ngb8o1"
   Home → Alignment
   ```

5. Select:

   ```text id="jlwm9q"
   Center
   ```

---

## Result

Headings become more visible and professional.

---

# Use Wrap Text

## Purpose

Prevent extremely wide columns.

---

## Steps

1. Select long headings

2. Go to:

   ```text id="b8kh3x"
   Home → Alignment
   ```

3. Choose:

   ```text id="nnrh7y"
   Wrap Text
   ```

---

## Result

Text displays across multiple lines.

---

## Best Practice

Use Wrap Text instead of oversized columns.

---

# Hide Worksheet

## Purpose

Temporarily remove unnecessary sheets without deleting data.

---

## Steps

1. Select worksheet

2. Go to:

   ```text id="mjlwm8"
   Home → Cells Group
   ```

3. Choose:

   ```text id="9cglhj"
   Format → Hide & Unhide
   ```

4. Select:

   ```text id="9ru8c4"
   Hide Sheet
   ```

---

## Result

Worksheet becomes hidden but recoverable later.
