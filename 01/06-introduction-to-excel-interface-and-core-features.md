## Excel Interface Overview

### 1. Title Bar

Located at the top of Excel.

Contains:

* File name
* Search box
* Autosave
* Undo button

---

### 2. Worksheet Grid

Main working area in Excel.

Made of:

* Rows
* Columns
* Cells

A cell is created where:

> A row and column intersect.

Example:

```text id="7u7z3z"
A1
B5
D10
```

---

### 3. Formula Bar

Displays:

* Cell contents
* Formulas
* Calculations

Important concept:

* Cell shows result
* Formula bar shows actual formula

Example:

Cell displays:

```text id="vz9ffu"
500
```

Formula bar may contain:

```excel id="z0lj50"
=250+250
```

---

## Command Tabs (Ribbons)

Excel commands are grouped into tabs called ribbons.

These tabs organize tools by functionality.

---

# Important Excel Tabs

## Home Tab

Most frequently used tab.

Used for:

* Formatting
* Copy/paste
* Sorting
* Basic editing

---

## Insert Tab

Used to add:

* Charts
* Tables
* Shapes
* Comments

---

## Draw Tab

Used for:

* Drawing
* Marking worksheets
* Ink tools

---

## Page Layout Tab

Controls:

* Printing layout
* Margins
* Orientation
* Themes

---

## Formulas Tab

Used for:

* Functions
* Formula management
* Calculation tools

Very important for data analysis.

---

## Data Tab

One of the most important tabs for analysts.

Used for:

* Sorting
* Filtering
* Queries
* Data transformation

Important for:

* Power Query
* Cleaning datasets
* Managing large data blocks

---

## Review Tab

Used for:

* Comments
* Collaboration
* Protection
* Security settings

---

## View Tab

Used to improve spreadsheet navigation.

Important feature:

### Freeze Panes

Keeps headers visible while scrolling large datasets.

Very useful in real-world analysis.

---

## Contextual Tabs

Special tabs that appear only during certain actions.

Example:

Selecting a chart may show:

* Chart Design
* Format tabs

These tabs contain chart-specific tools.
