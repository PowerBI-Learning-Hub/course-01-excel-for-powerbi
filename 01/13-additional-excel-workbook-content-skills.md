# Use Wildcards in Searches

## Purpose

Perform flexible searches.

---

## Common Wildcards

| Wildcard | Meaning             |
| -------- | ------------------- |
| `*`      | Multiple characters |
| `?`      | Single character    |

---

## Example

```text id="jlwm8x"
Sales*
```

Finds:

* Sales2025
* Sales_Q1
* SalesReport

---

# Merge Cells

## Purpose

Create centered worksheet titles.

---

## Steps

1. Select multiple cells

2. Go to:

   ```text id="jlwm9k"
   Home → Alignment
   ```

3. Choose:

   ```text id="jlwm9p"
   Merge & Center
   ```

---

## Result

Selected cells combine into one larger cell.

---

## Important Warning

Avoid excessive merging in analytical datasets.

Merged cells can:

* break sorting
* cause filtering problems
* create Power BI import issues

---

# Unmerge Cells

## Steps

1. Select merged cell

2. Choose:

   ```text id="zjlwm0"
   Unmerge Cells
   ```

---

# Apply Borders

## Purpose

Improve worksheet readability visually.

---

## Common Border Uses

* Separate sections
* Highlight totals
* Create table structures

---

## Steps

1. Select cells

2. Go to:

   ```text id="jlwm0g"
   Home → Font Group
   ```

3. Select:

   ```text id="jlwm0m"
   Borders
   ```

---

## Common Border Types

| Border        | Usage              |
| ------------- | ------------------ |
| Bottom Border | Totals             |
| All Borders   | Tables             |
| Thick Border  | Important sections |

---
